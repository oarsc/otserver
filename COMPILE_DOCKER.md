## Creating Docker Image

Create the docker image by using the Dockerfile with:
```sh
./do
```

## Compiling and running the code

In order to compile the code, simpy run
```sh
./compile.sh

# or execute this to run it directly on docker
./do compile.sh
```

To run the server:
```sh
./otserv

# or execute this to run it directly on docker
./do compile.sh
```
